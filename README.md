# Chess 3D

Self-contained 3D Chess application built with React, Three.js (`@react-three/fiber`, `@react-three/drei`, `@react-spring/three`), `chess.js`, and Tailwind CSS.

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

This outputs a static bundle to `dist/`, ready to deploy to any static host or subdomain (Netlify, Vercel, Cloudflare Pages, GitHub Pages, etc.).
